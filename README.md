# Lovora landing page

Static responsive landing page for Lovora's personalized celebration websites.

## GitHub Pages / Vercel

Upload the **contents** of this folder to the repository root. Keep the `assets` folder alongside `index.html`.

```text
index.html
README.md
assets/
  theme-midnight-chic.jpg
  theme-flower-fairy.jpg
  theme-soft-glam.jpg
  theme-lavender-dream.jpg
  theme-golden-hour.jpg
  theme-cherry-pop.jpg
```

- GitHub Pages: configure Pages to publish from the main branch and the root `/` folder.
- Vercel: choose the `Other` framework preset; no build command is needed for this static website.
- Instagram contact link: https://www.instagram.com/lovora.wish/

Prices aren't hard-coded. Visitors are directed to Instagram for a quote and confirmation of any custom-domain costs.

Note: the gallery uses the six photos supplied for this mockup as visual theme inspiration. Use images you have permission to publish in your final commercial site.
